# Interactive Quiz Application

A browser-based quiz application built with HTML, CSS, and JavaScript.

## Features

- Five multiple-choice course questions
- One question displayed at a time
- Score tracking for correct answers
- Final score shown after completing the quiz
- Responsive blue, white, and gold interface

## Technologies Used

- HTML
- CSS
- JavaScript

## Run Locally

1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Answer all five questions to see your final score.

## How It Works

The quiz questions are stored in a JavaScript array. The application displays each question and its options, checks the selected answer, tracks the score, and displays the result when the quiz is complete.
